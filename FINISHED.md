# The `finished` branch

What the project looks like after all five steps, for reference when you are
stuck. Compare, copy what you need, keep going.

**Two things are here that will not be in your own repository**, on purpose:

- `documents/` is in `.gitignore`. It is committed here (with `git add -f`) only
  so you can see the names and sidecars. In your copy it stays out of git.
- `brain/` is its own private repository in your copy (Step 2b). Here it is a
  plain folder so you can read the notes.

`drafts/2026-10.json` is the categorized October that `monthly-summary` writes;
run `python3 .claude/skills/monthly-summary/scripts/total.py drafts/2026-10.json`
to see the totals. The milestones and issues from Step 4b live on GitHub, not
in files, so they are not here.
